# Xocolata Brain

Base de conocimiento organizada del proyecto **Xocolata Food Premium**: negocio, producto, estrategia B2B, marketing, operación, feria de Miami e inversión. Construida a partir de notas de reuniones, decks y material de marca subidos por el equipo.

**Empieza por [00-resumen-ejecutivo.md](00-resumen-ejecutivo.md)** — punto de entrada rápido con enlaces a cada sección. Para seguimiento semana a semana con checklist, usa [roadmap.md](roadmap.md).

## Fuentes originales

Los documentos fuente (PDFs, imágenes de marca, capturas de WhatsApp) que dieron origen a estas notas viven sin versionar en `../Datos Xocolata/`, fuera de este repo. Este repo solo contiene el texto limpio y organizado.

## Cómo mantener esto vivo

Cuando haya una reunión, decisión o cambio de plan nuevo:
1. Actualiza el archivo temático correspondiente (no crees uno nuevo si ya existe uno del mismo tema).
2. Si algo queda pendiente o contradice un documento anterior, anótalo en [decisiones-abiertas.md](decisiones-abiertas.md).
3. Si cambia algo del panorama general, actualiza [00-resumen-ejecutivo.md](00-resumen-ejecutivo.md).
4. Haz commit con un mensaje corto que describa el cambio.

Ver [CLAUDE.md](CLAUDE.md) para las convenciones completas de este repo.
